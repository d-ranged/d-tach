Detection

What counts as an identifying value. Names and email addresses are always detected; the rest are opt-in because each one is as likely to remove meaning as to protect anyone. Saved immediately and used by every mode.

Ubiquitous in academic documents — off by default.
Overlaps with email detection — can garble output.
City and country names often carry meaningful context.
Exact digit count — student numbers, employee numbers.
Document Mode only — text has no filenames.

Known values

Values the anonymizer consistently misses. Every one listed here is replaced in every run, across Text, Document, and AI mode.

Import from class list

Read a roster spreadsheet and add its columns as known values in bulk. A class of 500 with a name column and a number column adds over a thousand values, so imported values are summarised rather than listed — search below to find and remove a specific one.

Hashing

Replaces numbered placeholders like [PERSON_1] with stable ones derived from a secret, so the same person encodes to the same token in every document, in every mode, and in every session. Set the secret once and leave it: change it and every placeholder changes with it.

Treat the secret as sensitive. Anyone holding both it and a list of candidate names can reproduce the tokens and undo the pseudonymization.

Excel (.xlsx)

How spreadsheet cells are handled. If both options below are off, Excel files are skipped entirely rather than copied unchecked.

Runs name detection over string cells.

Comma-separated. Replaces every value in those columns regardless of type, which is how numeric IDs get caught. Requires column headers in row 1. Does not affect DOCX, PDF, or Markdown.

Folder output

Where Document Mode writes results when processing a whole folder. These do not apply to a rename-only pass, which changes names in place.

Comma-separated. Files with these extensions are copied into the output as-is, with no PII scanning at all. Empty by default.

AI Mode

Lets a local AI agent request anonymized text from files on this machine and, when producing final output, ask for real values to be restored straight to disk — without the real values ever passing through the agent's own context. Off by default.

Sent by the AI agent as the X-D-Tach-Token header on every request. Regenerating invalidates the previous token immediately.

Paste this into the agent's system prompt or CLAUDE.md so it knows the rules for using AI Mode.

Larger extractions are written to the temp folder instead of returned directly, to avoid flooding the AI's context window.
